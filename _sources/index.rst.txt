=====

       <img class="hero-logo" src="_static/logo.png" alt="HORUS">
       <p><b>Human Oriented Robotic Unified System</b>: an open-source framework for robots that
       physically interact with people, such as lower-limb exoskeletons, wearable sensors and,
       later, prostheses and stimulators. Built the way nav2 is built for navigation, on top of
       ros2_control for the real-time loop.</p>

How HORUS works
---------------

.. grid:: 1 2 3 3
   :gutter: 3

   .. grid-item-card:: :octicon:`broadcast;1.2em` Sensing
      :link: docs/concepts/sensing_estimation
      :link-type: doc

      Drivers publish raw data on ``/sensors``; HORUS nodes calibrate it per subject.

   .. grid-item-card:: :octicon:`pulse;1.2em` State estimation
      :link: docs/concepts/sensing_estimation
      :link-type: doc

      The calibrated state of the person and the robot, published on ``/human``.

   .. grid-item-card:: :octicon:`shield-check;1.2em` Supervisor
      :link: docs/concepts/decision_hierarchy
      :link-type: doc

      One mode says who may move the device: standby, run, manual, recovery, emergency stop.

   .. grid-item-card:: :octicon:`workflow;1.2em` Behavior trees
      :link: docs/configuration/supervisor_trees
      :link-type: doc

      The protocol, as XML, run by the supervisor: home, walk, calibrate, record, recover.

   .. grid-item-card:: :octicon:`graph;1.2em` Generation
      :link: docs/concepts/motion
      :link-type: doc

      Plugins turn a behavior into a joint reference at about 100 Hz.

   .. grid-item-card:: :octicon:`cpu;1.2em` Control
      :link: docs/configuration/controllers
      :link-type: doc

      ros2_control tracks it in real time, behind a safety controller, on a mock, in MuJoCo or on the device.

.. code-block:: bash

   # run the whole system on the built-in mock exoskeleton
   ros2 launch horus_bringup rig.launch.py \
     rig:=$(ros2 pkg prefix horus_bringup)/share/horus_bringup/rigs/mock/rig.yaml
   # then open http://<this-pc>:8080 from a phone, tablet or laptop
