Detailed Description
--------------------

Targets arrive as sensor_msgs/JointState on ``topic`` (names + position, or + effort for ``quantity: effort``); joints not named keep their target. The output moves toward the target at most ``max_rate`` per second (rad/s or N m/s), so a slider jump is a ramp, never a step. Position output starts at the measured pose; effort output starts at zero. With no target for ``timeout`` s the target freezes at the current output (hold). Continuous: runs until the behavior is canceled.

manual: plugin: horus_generator_pattern/Manual joints: [hipR, kneeR, ankleR] quantity: position # position | effort max_rate: 0.5 # rad/s (position) or N m/s (effort) min: [-0.5, 0.0, -0.3] # optional clamp per joint (default: none) max: [ 0.8, 1.2, 0.3] timeout: 1.0 # s without a target -> hold topic: ~/manual_target
