class Pattern : public horus_generator_core::Generator

Plays a configured waveform per joint at a shared cadence.

Public Functions

void configure(const horus_generator_core::NodePtr &node, const std::string &name) override

Read the signal list, waveform parameters and the cadence.

Parameters:

  • node – The hosting lifecycle node, used for parameters and logging.

  • name – This instance’s parameter namespace; parameters live under <name>.*.

virtual void activate() override

Become the active generator; the phase continues from where reset() left it.

virtual void deactivate() override

Stop being the active generator.

virtual void reset() override

Rewind the phase and the completed-cycle count to zero.

virtual std::vector<double> update(const rclcpp::Time &time, const rclcpp::Duration &period) override

Advance the phase and sample every signal.

Parameters:

  • time – Current time (unused, the pattern integrates period instead).

  • period – Time since the previous tick, which advances the phase.

Returns:

One value per signal, in signals order, in the controller’s units.

virtual bool finished() const override

Whether a finite pattern has run its course.

Returns:

True once a non-cycling pattern has completed one cycle; always false when cycling.
