Detailed Description

On-disk store of calibration files, shared by every HORUS channel node.

Layout: <data_root>/subjects/<subject>/calibration/<node>/<unit>_<YYYYmmdd_HHMMSS_mmm>.yaml. Every save is a new file (history is kept); the latest file of a unit is the newest timestamp. A file holds node, unit, plugin, created_at and the plugin's data.
