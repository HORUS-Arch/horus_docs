Detailed Description
--------------------

A channel node (horus_imu, horus_insole, horus_emg, ...) owns the data flow, the files and the ROS interfaces; the plugin owns only the math. During a calibration run the node feeds raw samples of the units being calibrated to add(); finish() turns them into a YAML result; load() applies a result (fresh or from file); apply() corrects every live sample. Swapping the algorithm is a one-line change of ``calibration.plugin`` in the node's YAML.

Threading: the node serialises every call under one mutex, so plugins need no locking.
