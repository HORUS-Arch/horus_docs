horus_control
=============

HORUS ros2_control layer. Reserved for the model-based controllers HORUS will ship
    (URDF gravity compensation, impedance, admittance); currently empty, everything a device needs
    today is stock ros2_control, and firmware command conventions live in the device's repo.
