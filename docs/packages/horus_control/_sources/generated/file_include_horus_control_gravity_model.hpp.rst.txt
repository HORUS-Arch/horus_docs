Detailed Description
--------------------

The chain runs from ``root`` to ``tip`` in the URDF; its movable joints must be exactly the joints the controller commands (any order). compute() returns, for a joint configuration q, the torque that holds every link of the chain still against gravity, G(q). Links need <inertial> data.
