SupervisorState

This is a ROS message definition.

Source

# The supervisor's global mode (latched, published on every change). A mode answers one question:
# who may move the device right now? Safety events always win: an emergency stop, a fault of a
# critical device or a lost operator drive the supervisor to EMERGENCY_STOP from any mode.
uint8 INIT           = 0   # starting; no operator yet; nobody moves the device
uint8 STANDBY        = 1   # ready and idle; nobody moves the device (setup, calibration, recording happen here)
uint8 RUN            = 2   # the protocol tree moves the device
uint8 MANUAL         = 3   # the operator moves the device (joint sliders)
uint8 RECOVERY       = 4   # the protocol failed; the recovery tree moves the device to a safe state
uint8 EMERGENCY_STOP = 5   # halted and latched; RESET (refused while a fault is active) -> STANDBY
uint8 mode
uint8 previous_mode
string mode_name                     # "RUN", ...
string reason                        # why the last transition happened
string tree                          # tree running for this mode ("" = none)
builtin_interfaces/Time since        # when the current mode was entered
string[] faults                      # critical sources in ERROR / STALE (block RESET)
string[] warnings                    # non-critical sources in ERROR / STALE, or any source in WARN
bool operator_connected              # operator heartbeat alive (true when heartbeat is disabled)
string[] protocols                   # registered tree ids the operator can START
