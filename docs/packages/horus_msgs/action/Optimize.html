Optimize

This is a ROS action definition.

Source

# Run a human-in-the-loop optimization of a behavior's parameters. The optimization server proposes
# candidates, applies each to `behavior`, collects CostSample's for `cycles_per_candidate` cycles and
# iterates until the optimizer converges, `max_candidates` is reached, or the goal is canceled.
string behavior                  # generator behavior whose parameters are optimized
string optimizer                 # optimizer plugin name (key in the server's `optimizer_plugins`)
string cost                      # cost plugin name (key in the server's `cost_plugins`)
uint32 cycles_per_candidate      # cost samples averaged per candidate (0 = server default)
uint32 max_candidates            # stop after this many candidates (0 = optimizer decides)
---
# Outcome is the built-in action_msgs/GoalStatus; error_code says WHY (nav2's action convention).
uint16 NONE = 0
uint16 UNKNOWN = 1000
uint16 BEHAVIOR_NOT_FOUND = 1001
uint16 OPTIMIZER_NOT_FOUND = 1002
uint16 COST_NOT_FOUND = 1003
uint16 OPTIMIZATION_FAILED = 1004
uint16 error_code
string error_msg
Candidate best                   # best candidate found
float64 best_cost
string results_path              # where the full history was saved
---
Candidate current                # candidate being evaluated
uint32 cycles_done               # cost samples collected for it so far
Candidate best                   # best so far
float64 best_cost
