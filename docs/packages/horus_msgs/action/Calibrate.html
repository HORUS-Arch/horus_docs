Calibrate

This is a ROS action definition.

Source

# Run a calibration on a HORUS processing node (horus_imu, horus_insole, horus_emg, ...). The node
# collects data for `duration` seconds and computes the calibration with its configured plugin; the
# result stays PENDING in the node until ~/save_calibration writes it for a subject.
string unit             # channel to calibrate (a segment, a muscle, a side); "" = all channels at once
float32 duration        # seconds of data to collect (0 = the plugin's default)
---
# Outcome is the built-in action_msgs/GoalStatus; error_code says WHY (nav2's action convention).
uint16 NONE = 0
uint16 UNKNOWN = 1100
uint16 UNIT_NOT_FOUND = 1101
uint16 NOT_ACTIVE = 1102          # the node must be active (streaming) to calibrate
uint16 NO_DATA = 1103             # no samples arrived during the window
uint16 CALIBRATION_FAILED = 1104  # the plugin rejected the data (e.g. subject moved)
uint16 error_code
string error_msg
string[] units                    # units that were calibrated (pending save)
string summary                    # short human-readable result, e.g. "mvc 0.42 mV"
---
string unit                       # unit being collected
float32 progress                  # 0.0 .. 1.0
string message
