SessionControl

This is a ROS service definition.

Source

# The session: which subject is selected, and whether a trial (recording) is open. SELECT pushes the
# subject to every HORUS sensing node, which loads its newest calibrations. START opens a trial for
# the selected subject (or `subject_id`); STOP closes it. With `record: per_run` the session also
# opens a trial when the supervisor enters RUN and closes it back in STANDBY.
uint8 START  = 0
uint8 STOP   = 1
uint8 SELECT = 2
uint8 command
string subject_id        # SELECT: the subject ("" = none); START: optional, selects it first
string[] topics          # START: optional topics to record (empty = the recorder's configured set)
---
bool success
string message
string trial_id          # set on START
