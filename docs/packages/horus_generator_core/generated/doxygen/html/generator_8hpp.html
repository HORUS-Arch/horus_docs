Detailed Description

The abstract Generator plugin interface loaded by generator_server via pluginlib.

A generator produces a reference vector each tick (joint set-points, or a scalar for a torque loop) that the server publishes to a controller. Concrete plugins are sine/pattern, a trajectory player (sit / stand / home from a CSV or keyframe file), DMP, CPG, ML.

There is NO rigid per-tick input struct: a closed-loop generator (CPG, ML) subscribes the inputs it needs itself, using the node handle passed to configure(). The server owns only the rate thread, publishing and lifecycle, so update() receives just time and period.

The interface is lifecycle-shaped, which lets the server be a managed lifecycle node without any plugin having to know about lifecycle transitions.
