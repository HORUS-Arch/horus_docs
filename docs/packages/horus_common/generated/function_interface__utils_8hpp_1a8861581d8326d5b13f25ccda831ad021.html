Function Documentation

template<typename NodePtr>
inline bool horus_common::param_or_zeros(const NodePtr &node, const std::string &name, size_t n, std::vector<double> &out)

Read a per-joint double-array param, defaulting to zeros when it is unset.

Parameters:

  • node – Handle providing get_parameter() + get_logger().

  • name – Parameter name, e.g. “stiffness”.

  • n – Expected number of entries (the joint count).

  • out – Filled with the parameter values, or n zeros when the parameter is unset.

Returns:

True on success, false (after logging) if the param is set but its length is not n.
