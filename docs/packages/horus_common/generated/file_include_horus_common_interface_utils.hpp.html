Detailed Description

HORUS components never hardcode which hardware interface they bind: the names come from params, so one binary serves every device. These helpers factor out the loading each of them would otherwise repeat, reading the param, filling a sensible default when it is unset, and validating the length against the joint list. Both return false (after logging) so the caller can fail configuration.

Header-only and templated on the node handle, so anything with get_parameter() + get_logger() works.
