horus_setup_assistant.generate module

Scaffold a new HORUS device repo (the “make my device HORUS-ready” tool).

ros2 run horus_setup_assistant generate –name mydevice –joints hipR,kneeR,ankleR –out ~/dev

Generates an INDEPENDENT device package <name>_ros2/ (franka_ros2 model) that DEPENDS ON core (never copies it):

  • urdf/<name>.urdf.xacrokinematics + ros2_control from the horus_mock_device macros,

    with a hardware selector (mock | mujoco | real plugin)

  • config/<name>_controllers.yaml : config-driven controllers (interaction interfaces from YAML)

  • package.xml / CMakeLists.txt / README.md

and prints the catalog entry + the line to add to your PROJECT workspace’s .repos. Edit the geometry/gains, set your real hardware plugin, and it plugs into HORUS. This is its own git repo, composed into a project workspace next to pinned horus, NOT cloned into core. (MoveIt-Setup-Assistant analog; CLI first, GUI later.)
