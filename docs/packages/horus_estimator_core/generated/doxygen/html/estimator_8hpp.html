Detailed Description

Abstract state estimator for stage-2 state estimation (joint kinematics, gait events and phases, interaction torque, base orientation), loaded by pluginlib.

Mirrors the Generator interface: lifecycle-shaped, and with no fixed per-tick input structure. An estimator subscribes to the inputs it needs (stage-1 human state on /human, robot state on /robot or the ros2_control broadcasters) through the node handle it receives in configure(), and publishes its own standard or human_msgs outputs. update() is called at the host's rate.
