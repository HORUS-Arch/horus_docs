Detailed Description

The calibration plugin base classes of the horus_human nodes, one per input message type.

Write a new calibration algorithm by deriving from one of these, exporting it with PLUGINLIB_EXPORT_CLASS(MyCalibration, horus_human::ImuCalibration) and pointing the node's calibration.plugin parameter at it. No node code changes.
