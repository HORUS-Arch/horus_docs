Detailed Description
--------------------



- ImuStaticPose the subject holds a known reference pose (default: upright, all segments aligned with the world frame); computes the sensor-to-segment rotation and the gyro bias, and rejects the window if the subject moved.

- InsoleZeroOffset the foot is unloaded (lifted / seated); stores the per-cell pressure and total-force offsets.

- EmgMvc the subject performs a maximum voluntary contraction; stores the peak of the envelope, by which live EMG is then normalised.
