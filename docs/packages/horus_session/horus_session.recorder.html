horus_session.recorder module

Trial recorder: records topics into <data_root>/subjects/<subject_id>/trials/<trial_id>/bag/ and keeps that trial’s trial.yaml (metadata, calibrations used, notes, events, outcome). A plain helper owned by the session node (not a node): it runs ros2 bag record as a subprocess.

Topic selection (precedence): the START request’s topics (per-session override) > record_all (default TRUE -> ros2 bag record -a, minus exclude) > the explicit topics subset. Recording ALL by default keeps the recorder device-agnostic: it captures whatever the running devices publish without core knowing device-specific topic names.
