Detailed Description

HORUS BT leaves that act on the system rather than on the robot:

<EmergencyStop reason="pain reported"> supervisor -> EMERGENCY_STOP (always SUCCESS) <StartRecording> <StopRecording> open / close a trial on /horus/session <AddTrialNote text="rest 60 s"> note in the running trial <SetSpeedScale value="0.8"> live speed of every generator behavior

Service leaves call on a private callback group drained on every tick (container-agnostic, like the other leaves) and fail after timeout s without a reply.
