Detailed Description

HORUS BT condition and wait leaves: IsAtPose, IsHealthy, WaitForMessage.

<IsAtPose joints="hipR,kneeR" positions="0,0" tolerance="0.05"> joints within tolerance <IsHealthy source="imus"> no diagnostic ERROR <WaitForMessage topic="/human/gait/events" type="human_msgs/msg/GaitEvent" timeout="5.0">

Each leaf subscribes on its own callback group, drained on every tick, so it works standalone or composed. Conditions never return RUNNING; WaitForMessage is RUNNING until a message arrives after it started (SUCCESS) or the timeout passes (FAILURE).
