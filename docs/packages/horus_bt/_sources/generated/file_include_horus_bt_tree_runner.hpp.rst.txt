Detailed Description
--------------------

Loads every BT XML of the given folders, registers the HORUS leaves, and ticks one tree at a time. start() and stop() never block: the tick thread picks the request up within microseconds, halts the running tree and builds the next one, so a mode change never waits for a tick. The result of a tree is reported once through its callback, with the id given to start(); a tree that is replaced or stopped reports nothing.
