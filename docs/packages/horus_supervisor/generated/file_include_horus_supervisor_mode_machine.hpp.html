Detailed Description

A mode answers one question: who may move the device right now? INIT, STANDBY nobody (setup, calibration and recording happen in STANDBY) RUN the protocol tree MANUAL the operator (joint sliders) RECOVERY the recovery tree, after the protocol failed EMERGENCY_STOP nobody; latched until RESET, which is refused while a fault is active Events are handled the moment they arrive (no tick queue). Classes, from highest priority: 0 safety ESTOP, FAULT, OPERATOR_LOST -> EMERGENCY_STOP, always accepted 1 escalation TREE_FAILED -> RUN: RECOVERY, RECOVERY: EMERGENCY_STOP 2 operator READY, START, STOP, MANUAL, RESET -> arbitrated, rejected if not allowed 3 progress TREE_SUCCEEDED -> RUN / MANUAL / RECOVERY: STANDBY Because safety transitions are valid in every mode, any interleaving of a safety event with a request ends in EMERGENCY_STOP. A request that is not allowed is rejected, never an error.
