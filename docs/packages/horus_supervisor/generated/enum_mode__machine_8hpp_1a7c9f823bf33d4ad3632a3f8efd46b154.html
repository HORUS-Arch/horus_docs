enum class horus_supervisor::Event : int

Inputs to the machine.

Values:

enumerator ESTOP

operator, hardware or tree emergency stop

enumerator FAULT

a critical source reported ERROR or went stale

enumerator OPERATOR_LOST

operator heartbeat timed out

enumerator TREE_FAILED

the current mode’s tree failed (escalation)

enumerator READY

system up and operator connected: leave INIT

enumerator START

operator: run a protocol

enumerator STOP

operator: stop the protocol / leave manual

enumerator MANUAL

operator: take manual control

enumerator RESET

operator: leave EMERGENCY_STOP

enumerator TREE_SUCCEEDED

the current mode’s tree completed
