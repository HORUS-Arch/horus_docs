HORUS#

ROS 2 Jazzy · human-interacting robotics

Human Oriented Robotic Unified System: an open-source framework for robots that physically interact with people, such as lower-limb exoskeletons, wearable sensors and, later, prostheses and stimulators. Built the way nav2 is built for navigation, on top of ros2_control for the real-time loop.

Supervisor

Decision hierarchy
Behavior trees

The protocol, as XML, run by the supervisor: home, walk, calibrate, record, recover.

Generation

Plugins turn a behavior into a joint reference at about 100 Hz.
